# ts-to-vlc-ps5 — Lampa → VLC для PS5

Мост для запуска видео из **Lampa** во **VLC for PS5**. Плагин Lampa передаёт готовый HTTP/HTTPS-адрес потока локальному `vlc-bridge.elf`, мост записывает файл `autoplay.txt` в каталог VLC и запускает плеер.

**Успешно проверено на PS5 с [VLC for PS5 0.6.1](https://github.com/ZiZc3/VLC):** после выбора торрента в Lampa автоматически открывается VLC и начинается воспроизведение потока от TorrServer.

> Это не самостоятельная версия Lampa для PS5 и не отдельный видеоплеер. Для выбора фильма Lampa должна быть открыта на консоли, например в [ProsperoWeb](https://github.com/kvaps/ProsperoWeb).

## Схема работы

```text
Lampa на PS5 (например, в ProsperoWeb)
      |
      | Lampa.Player.play: URL фильма или серии
      v
Плагин http://127.0.0.1:8766/lampa.js
      |
      | GET /play?url=...&title=...
      v
vlc-bridge.elf — HTTP-сервер на порту 8766
      |
      | создаёт /data/homebrew/PPSA85300/autoplay.txt
      | запускает приложение PPSA85300
      v
VLC for PS5 0.6.1 — воспроизводит поток
```

Мост **не скачивает торренты**, не выполняет поиск и не транскодирует видео: он получает от Lampa уже готовый URL. TorrServer и торрент-источники настраиваются отдельно.

## Что нужно установить

1. PS5 с возможностью запуска homebrew и ELF/payload (например, etaHEN и совместимый ELF-загрузчик).
2. [VLC for PS5](https://github.com/ZiZc3/VLC) **0.6.1** с поддержкой `autoplay.txt` — именно эта версия протестирована.
3. Lampa, работающую на **самой PS5**, например в [ProsperoWeb](https://github.com/kvaps/ProsperoWeb).
4. Для торрентов: настроенный в Lampa источник и доступный TorrServer, который выдаёт ссылку для потокового воспроизведения.
5. `vlc-bridge.elf` из сборки данного репозитория.

## 1. Установите VLC во внутреннюю память

**Критически важно:** в текущем коде путь к VLC жёстко задан:

```text
/data/homebrew/PPSA85300/
    eboot.bin
    ... остальные файлы VLC
```

Сюда мост будет создавать файл:

```text
/data/homebrew/PPSA85300/autoplay.txt
```

Если VLC находится на **USB-флешке**, например `/mnt/usb0/homebrew/PPSA85300/`, мост его **не найдёт**. В ходе тестирования это приводило к `file=0 bytes=0 errno=2` и открытию VLC без видео. После переноса VLC в `/data/homebrew/PPSA85300/` воспроизведение из Lampa **заработало**.

Альтернатива для разработчиков: исправить `AUTOPLAY_FILE` в `main.c` под реальный каталог и пересобрать мост. Автоматического поиска по USB в текущей версии нет.

Для первого запуска и тестирования **полностью закройте VLC** перед выбором видео в Lampa.

## 2. Скачайте и запустите мост

1. Перейдите в [GitHub Actions](https://github.com/Steinus/ts-to-vlc-ps5/actions).
2. Откройте последний **успешный** запуск workflow `build`.
3. В **Artifacts** скачайте архив `vlc-bridge` и распакуйте файл `vlc-bridge.elf`.
4. Передайте `vlc-bridge.elf` на PS5 и запустите его привычным ELF/payload-загрузчиком (etaHEN / elfldr и т. п.).
5. Мост не показывает интерфейс и продолжает работать как HTTP-сервер на **порту 8766**.

Проверка на **самой PS5**:

```text
http://127.0.0.1:8766/ping
```

Должен появиться ответ `ok`.

Проверка с компьютера в домашней сети (вместо `IP_PS5` — IP консоли):

```text
http://IP_PS5:8766/ping
```

**Не путайте порты:** `8766` — наш мост. Порт `8090` в ссылках вида `http://IP_TORRSERVER:8090/stream/...` — это пример порта **TorrServer**, а не моста. Старый README ошибочно советовал использовать `8090` для моста.

## 3. Укажите плагин в Lampa

Откройте Lampa **на PS5**, затем **Настройки → Расширения → Добавить плагин** и введите:

```text
http://127.0.0.1:8766/lampa.js
```

Сохраните адрес. Если плагин не подхватился сразу, перезагрузите страницу Lampa.

**Ничего копировать в каталог VLC для плагина не нужно:** `plugin.js` встроен в `vlc-bridge.elf` на этапе сборки и раздаётся мостом по `/lampa.js`.

**Важно:** `127.0.0.1` обозначает устройство, **на котором открыта Lampa**. При запуске Lampa на ПК/телефоне такой адрес ведёт к ПК/телефону, а не к PS5. Если нужен удалённый клиент, измените `BRIDGE` в `plugin.js` на `http://IP_PS5:8766`, затем пересоберите `vlc-bridge.elf`. Стандартная сборка рассчитана на Lampa и мост **на одной консоли**.

## 4. Как воспроизводить

1. Запустите мост. Убедитесь, что `/ping` отвечает `ok`.
2. Полностью закройте VLC (для первого теста).
3. Откройте Lampa на PS5 и убедитесь, что плагин установлен.
4. Выберите фильм/серию, подходящий торрент и нажмите **«Смотреть» / «Воспроизвести»**.
5. Плагин отправит URL в мост, мост запишет `autoplay.txt` и попросит PS5 запустить VLC.
6. VLC прочитает файл и начнёт воспроизведение. **Такой сценарий проверен с VLC 0.6.1.**

Пример вида ссылки, которую может передавать Lampa из TorrServer:

```text
http://192.168.1.42:8090/stream/Movie.mkv?link=TORRENT_ID&index=1&play
```

Здесь IP, порт, имя файла, `link` и `index` — **пример**, а не значения, которые нужно прописывать в код моста.

### Формат autoplay.txt

Мост записывает в файл две строки:

```text
http://192.168.1.42:8090/stream/Movie.mkv?link=TORRENT_ID&index=1&play
Название фильма
```

Первая строка — ссылка на видео, вторая — название. VLC 0.6.1 принимает этот формат. При обработке плеер может удалить `autoplay.txt`: это нормальное поведение.

Для отдельной проверки VLC можно вручную создать `autoplay.txt` в его каталоге **только с URL в первой строке**, полностью закрыть VLC и открыть его — воспроизведение должно начаться, если ссылка доступна и формат поддерживается.

## Диагностика

| Адрес на PS5 | Назначение |
| --- | --- |
| `http://127.0.0.1:8766/ping` | Ответ `ok` означает, что мост запущен |
| `http://127.0.0.1:8766/lampa.js` | Скрипт плагина Lampa |
| `http://127.0.0.1:8766/status` | Последний URL и сведения об `autoplay.txt` |
| `http://127.0.0.1:8766/play?url=...` | Ручная отправка URL (параметр должен быть URL-кодирован) |

С компьютера замените `127.0.0.1` на IP своей PS5. Например, в PowerShell:

```powershell
$ps5 = '192.168.1.92'  # замените IP на адрес своей PS5
Invoke-RestMethod ("http://" + $ps5 + ":8766/ping")
Invoke-RestMethod ("http://" + $ps5 + ":8766/status")
```

Чтобы **повторно отправить последнюю ссылку из Lampa** и увидеть результат записи файла:

```powershell
$ps5 = '192.168.1.92'
$s = Invoke-RestMethod ("http://" + $ps5 + ":8766/status")
$url = ([regex]::Match($s, '(?m)^last url: (.+)$')).Groups[1].Value.Trim()

if ($url) {
    curl.exe -i -G --data-urlencode "url=$url" ("http://" + $ps5 + ":8766/play")
} else {
    Write-Host "Мост пока не получал ссылок"
}
```

Типичный успешный ответ `/play`:

```text
launch=0 file=1 bytes=145 errno=0
```

- `file=1` — файл открыт для записи; `file=0` — создать файл не удалось.
- `bytes>0` — в файл записаны данные.
- `errno=0` — ошибки открытия файла не было.
- `launch=0` — системная команда запуска VLC выполнена без ошибки. Иное значение означает сбой запуска (например, VLC уже открыт).

**Внимание:** сообщение `gone (VLC took it)` в текущем `/status` **не доказывает**, что VLC прочитал файл. Код показывает его просто при **отсутствии `autoplay.txt`**, даже если мост вообще не смог создать файл. Для проверки записи используйте ответ `/play`: `file=1` и `bytes>0`.

### Частые проблемы

**`file=0 bytes=0 errno=2`.** Не существует каталог, в который пытаются записать `autoplay.txt`. Проверяйте `/data/homebrew/PPSA85300/`. Эта проблема воспроизводилась, когда VLC был на USB.

**VLC открывается, но показывает главный экран.** Убедитесь, что установлена версия с поддержкой `autoplay.txt` (проверено на 0.6.1), мост создал файл (`file=1`, `bytes>0`), VLC был закрыт перед запуском, а прямая ссылка открывается в VLC.

**Ошибка `launch=...`, когда VLC уже запущен.** Мост всё равно пытается вызвать запуск приложения. Обработки случая «VLC уже работает» в этой версии пока нет. Закройте VLC и повторите проверку.

**Lampa запускает свой плеер.** Плагин при недоступном мосте или HTTP-ошибке ответа вызывает обычное воспроизведение Lampa. Проверяйте `/ping`, `/status` и наличие плагина. При этом успешный HTTP-ответ моста **не гарантирует**, что VLC реально смог открыть видео.

**Нет связи с мостом.** Проверьте, что `vlc-bridge.elf` запущен, выбран правильный IP PS5 и порт **8766**.

## Сборка из исходников

Нужен [PS5 Payload SDK](https://github.com/ps5-payload-dev/sdk), `make` и `xxd`:

```bash
make PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk
```

`Makefile` сам создаёт `plugin.h` из `plugin.js` и компилирует `vlc-bridge.elf`. `plugin.h` вручную менять не нужно.

| Файл | Настройка | Значение |
| --- | --- | --- |
| `main.c` | `PORT` | `8766` |
| `main.c` | `TITLE_ID` | `PPSA85300` |
| `main.c` | `AUTOPLAY_FILE` | `/data/homebrew/PPSA85300/autoplay.txt` |
| `plugin.js` | `BRIDGE` | `http://127.0.0.1:8766` |

После изменений в `main.c` или `plugin.js` **пересоберите `.elf`**. Плагин перехватывает вызовы `Lampa.Player.play` для HTTP/HTTPS-URL (не только торренты). Если мост возвращает HTTP-ошибку или недоступен, он пробует штатный плеер Lampa.

## Ограничения и безопасность

- Мост слушает порт `8766` на всех сетевых интерфейсах PS5 и **не имеет авторизации**. Не открывайте этот порт в интернет; используйте только доверенную локальную сеть.
- Путь к VLC жёстко задан. Автопоиска VLC по USB нет.
- Обработка уже работающего VLC и достоверное подтверждение старта воспроизведения пока не реализованы.
- Отдельный ярлык Lampa на главном экране PS5 эта программа **не создаёт**: нужен браузер с открытой Lampa.
