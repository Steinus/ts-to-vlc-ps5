# vlc-bridge

1. Залей эту папку в новый репозиторий на GitHub -> вкладка Actions -> скачай артефакт `vlc-bridge.elf`.
2. Запусти .elf на PS5 своим загрузчиком payload (etaHEN / elfldr), VLC PS5 должен быть установлен.
3. Проверка: в ProsperoWeb открой http://127.0.0.1:8090/ping -> должно быть `ok`.
4. В Lampa: Настройки -> Расширения -> добавить плагин: http://127.0.0.1:8090/lampa.js
5. Нажми "Смотреть": ссылка уйдёт в мост, мост запишет её в
   /data/homebrew/PPSA85300/autoplay.txt и запустит VLC.

ВАЖНО: пока VLC PS5 не умеет читать autoplay.txt (см. feature request автору),
он просто откроется. Если мост недоступен, Lampa играет в своём плеере.
